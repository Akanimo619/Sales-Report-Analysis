# Sales-Report-Analysis

This project is an interactive Power BI sales report developed to provide a detailed view of sales performance across products, employees, zones and branches. The dashboard brings different aspects of the sales data together into a single reporting environment, making it possible to examine overall performance while also exploring the underlying details from different perspectives.

The report was designed to make sales information easier to understand through interactive visualisation. Instead of relying solely on the underlying data, the dashboard presents the information through dedicated views covering the overall sales dashboard, employee performance, product sales and the performance of different zones and branches.

The main sales dashboard provides an overview of the report and serves as the starting point for exploring the available information. The employee performance analysis provides a closer look at sales performance at employee level, while the product sales breakdown focuses on how sales are distributed across the different products represented in the dataset.

The zones and branches overview provides another perspective by allowing sales performance to be examined across different business locations. Bringing these views together makes it possible to move from an overall understanding of sales performance to more detailed analysis of the people, products and locations contributing to the results.

The dashboard was developed using Microsoft Power BI, with the report designed around interactive visualisations and business-focused analysis. The project demonstrates my approach to transforming business data into a reporting solution that can be used to explore performance and identify areas that may require further attention.

The Power BI source file is included in this repository as `Sales Report Analysis.pbix`. The screenshots folder contains previews of the main sections of the report.
